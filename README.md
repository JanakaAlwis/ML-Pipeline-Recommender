# ML Pipeline Recommender

Bachelor thesis project.

## Title

Design and Implementation of an Explainable Machine Learning Pipeline Recommendation System for Tabular Datasets

## Goal

This system analyzes tabular datasets and recommends suitable machine learning pipelines with explanations.

## Main Features

- CSV upload
- Dataset profiling
- Task detection
- Pipeline recommendation
- Model training
- Model comparison
- Explainability
- Report generation
- Streamlit dashboard

## Development Status

Planning stage.

## Implementation Phases

1. Dataset Loader
2. Dataset Profiler
3. Task Detector
4. Recommendation Engine
5. Preprocessing Builder
6. Model Trainer
7. Evaluator
8. Explainability
9. Report Generator
10. Web Application
